# Responsive Testimonial Cards

A collection of modern and responsive testimonial cards built with pure **HTML** and **CSS**.  
This is a practice project from [roadmap.sh](https://roadmap.sh) focused on layout, positioning, Flexbox, and CSS Grid.

---

## ✨ Features

- **Four distinct card designs**
  - **v1** – Speech-bubble style with a triangular pointer
  - **v2** – Clean bordered card
  - **v3** – Large image + rating stars + dark content panel
  - **Dynamic** – Centered message with profile selector (arrows + side profiles)
- Fully responsive using `clamp()`, `vw` units, CSS Grid, and Flexbox
- Custom **Montserrat** font (Regular, Medium, Bold)
- CSS custom properties for easy theming and consistency
- Circular profile photos with `clip-path` and `object-fit`
- SEO-friendly meta tags and semantic HTML
- Mobile-first and fluid typography

---

## 🛠️ Technologies

- HTML5
- CSS3 (Grid, Flexbox, Custom Properties, `clamp()`, `clip-path`, `aspect-ratio`)
- Self-hosted Montserrat font

## 🚀 Getting Started

1. Clone or download the repository.
2. Open `index.html` in any modern browser.
3. No build step or dependencies required — pure HTML & CSS.

```bash
# Optional: serve locally
npx serve .
# or
python -m http.server 3000
```

## 🎯 Learning Goals & Challenges

This project was built to practice and strengthen the following skills:

- Creating complex layouts with **CSS Grid** and **Flexbox**
- Using **CSS custom properties** for maintainable design tokens
- Building a speech-bubble effect with `::after` + `clip-path`
- Making cards fully responsive with `clamp()`, fluid units (`vw`), and `max()`
- Handling different card orientations and content structures in one page
- Writing clean, semantic, and SEO-ready HTML
- Organizing styles across multiple CSS files

## ✨ ویژگی‌ها

- **چهار طراحی مختلف کارت**
  - **نسخه اول (v1)** – سبک حباب گفتگو با اشاره‌گر مثلثی
  - **نسخه دوم (v2)** – کارت تمیز با حاشیه
  - **نسخه سوم (v3)** – تصویر بزرگ + ستاره‌های امتیاز + پنل محتوا تیره
  - **نسخه اسلایدر (Dynamic)** – پیام مرکزی همراه با انتخاب‌گر پروفایل (فلش‌ها + پروفایل‌های کناری)
- کاملاً واکنش‌گرا با استفاده از `clamp()`، واحدهای `vw`، CSS Grid و Flexbox
- فونت سفارشی **Montserrat** (Regular, Medium, Bold)
- استفاده از CSS Custom Properties برای تم‌سازی آسان
- عکس‌های پروفایل دایره‌ای با `clip-path` و `object-fit`
- تگ‌های متا مناسب SEO و HTML معنایی
- تایپوگرافی سیال و طراحی mobile-first
